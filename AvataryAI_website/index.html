About the Project

AvataryAI is a desktop AI assistant with a live 3D avatar. It speaks, listens, keeps up with today's news, and remembers your conversations across sessions. Built in Python by a 14-year-old student.

Brain
Gemini 2.5 Flash with web search
3D
Three.js live avatar
AES
Encrypted local memory
UA
Voice and Ukrainian speech recognition

Live 3D Avatar

A character in a minimalistic room moves its mouth when responding. Your own 3D model can be loaded in GLB format.

Current Knowledge

Gemini with built-in Google Search knows what's happening today — news, weather, prices. Not an outdated database.

Voice Control

Ukrainian speech recognition through Google Speech API. Responds with a neural network voice using Microsoft Edge TTS.

Memory Between Sessions

Remembers previous conversations. Stored locally in an encrypted file — no one except you has access.

Face Detection

MediaPipe FaceMesh tracks 468 points on the face through a webcam in real-time with minimal CPU load.

Weak Hardware

Light Mode disables heavy modules. Runs on laptops with 4 GB RAM without a dedicated graphics card.
